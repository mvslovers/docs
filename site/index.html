Manuals

Books for the mvslovers software for MVS 3.8j on Hercules: the CC/370 cross-toolchain, its C library LIBC/370, and the programs built with them. Each book is here to read online and as a PDF.

These pages follow the current development state of each project, so they may already describe changes that are not yet released. The edition that belongs to a release is attached as PDF to that release on GitHub.
