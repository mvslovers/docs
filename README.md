# docs

The landing page of [mvslovers.readthedocs.io](https://mvslovers.readthedocs.io):
a list of the mvslovers manuals. Each product's books are a Read the Docs
subproject built from that product's own repository (for example
`libc370/.readthedocs.yaml`), from the same Typst sources as the PDF manuals,
with the [bookmaster](https://github.com/mvslovers/bookmaster) template. The
look of every page is `bookmaster/web.css`.
